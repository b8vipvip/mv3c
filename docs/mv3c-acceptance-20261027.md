## 安全执行与证据

1. 先运行无写操作 `python3 mv3c/updater/host_acceptance.py --expected-version v0.1.28 --expected-sha c69f7148e9e9a689302c1d95eb85a5bedf5811d6`；脚本仅访问本机 GET 接口，不生成请求、账号或文件。
2. 在正常用户端手工测试游客会话标题/搜索、登录/后台；每次失败保留浏览器控制台和实际 HTTP 响应，注意删除 Cookie、Token 和个人数据。
3. A/B/C/D 使用真实自然任务分别运行；确认 chat2api、mv3c 和 Worker 三端一致结束及资源可下载，再逐项打勾。
4. 独立代理须先经宿主机连通性测试，不能将其他业务 Docker 容器的 SOCKS 端口当作长期基础设施。
5. 自动部署开关默认禁用。首次测试后台一键更新必须在正式版已发布且备份存在时执行；磁盘不足则拒绝导入，不自动删 Docker BuildKit 缓存。
