## 安全执行与证据

1. 先运行无写操作 `python3 mv3c/updater/host_acceptance.py --expected-version v0.1.32 --expected-sha fa3779ab375ef8ea3e40ae064cae08bfab02f0e0`；脚本仅访问本机 GET 接口，不生成请求、账号或文件。
2. 在正常用户端手工测试游客会话标题/搜索、登录/后台；每次失败保留浏览器控制台和实际 HTTP 响应，注意删除 Cookie、Token 和个人数据。
3. A/B/C/D 使用真实自然任务分别运行（提示词中不要写“测试/验证”）；保留 chat2api **原始请求 ID、后端终态/错误、请求完整导出**，以及 MV3C 对应会话、首字节/完成时间、渲染截图；确认 Worker 页面真实生成结束和三端终态一致后才标记通过。B 至少逐张打开三幅图片原图、确认三条不同资源 URL；C 必须实际下载 XLSX/PPTX/JSON/ZIP 并使用相应应用打开，不以仅出现 Markdown 链接为完成；D 复用同会话连续三轮。上传日志时遮盖 Cookie、API Token、签名 URL 的私密 token 段。
4. 独立代理须先经宿主机连通性测试，不能将其他业务 Docker 容器的 SOCKS 端口当作长期基础设施。
5. 自动部署开关默认禁用。首次测试后台一键更新必须在正式版已发布且备份存在时执行；磁盘不足则拒绝导入，不自动删 Docker BuildKit 缓存。
