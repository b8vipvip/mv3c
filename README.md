# mv3c

mv3c 是基于 [LibreChat](https://github.com/LibreChat-AI/LibreChat)（MIT License）开发的独立用户端，统一通过 [chat2api](https://github.com/b8vipvip/chat2api) 提供模型生成能力。

当前仓库正在初始化完整上游源码和 mv3c 品牌、部署配置。初始化完成后请查看 [mv3c/README.md](mv3c/README.md) 获取部署、账号和兼容性说明。

> 保留 LibreChat 的 MIT 许可与版权声明；mv3c 的用户账号和聊天记录独立于 chat2api。
